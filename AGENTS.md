# resume-ledger

This repository ships one Agent Skill: `skills/resume-ledger/SKILL.md`. Read it before any resume, CV, job-description or portfolio task. The skill's scripts live in `skills/resume-ledger/scripts/`; run them with Python 3.10+ (`pip install markdown pypdf`; Chrome/Chromium/Edge for PDF). Never store a user's facts, transcripts or drafts inside this repository; `scripts/init.py` creates the user's own project directory for that.
